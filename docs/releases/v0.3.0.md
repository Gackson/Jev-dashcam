Dashcam v0.3.0：新的名字与白底叠帧图标，支持迁移本地资料库，并完善话题编辑、归类和录制入口。

## 本次更新

- **正式更名为 Dashcam**，沿用应用标识 `ai.jevnote.mac`。
- **全新白底叠帧图标**：Apple Icon Composer 原生矢量分层，支持 macOS 26 的 Liquid Glass 深色、着色和透明外观；旧版 macOS 使用兼容图标。
- **可更改本地存储位置**：设置中选择空文件夹后，资料库、截图、配置及备份一并迁移；复制校验、新位置启动验证通过后才切换，原目录保留为迁移时的备份。
- **旧目录自动迁移**：默认目录更新为 `~/Library/Application Support/Dashcam/`，自动迁移旧版 `Jev Note/` 中的已有资料。
- **编辑话题标题和简介**：右键侧栏话题进入编辑，点击话题标题查看简介。编辑不重跑已有内容，新采集内容按更新后的话题信息分类。
- **可配置待归类内容保留时长**：1–720 小时，或一直保留。仅在持续录制时定期清理超过时长、仍等待首次分类的截图；暂停时不清理。
- **卡片右键操作**：可快速调整整组归属话题、删除整组，或只重试组内失败归类。
- **录制入口更清楚**：`Start Recording` 按钮使用录制标识，侧栏底部采集状态也可点击；添加话题入口集中到侧栏。
- **完善失败重试与示例体验**：重试放在归类失败页面和右键菜单中；重复点击体验示例会打开已有示例并明确提示。
- **优化组内详情布局**：缩略图条固定为紧凑高度，为下方截图详情留出空间。

## 下载与安装

1. 下载 **`Dashcam-v0.3.0-macos-arm64.zip`** 并解压，将 `Dashcam.app` 放入「应用程序」。无需安装 Node.js 或其他开发工具。
2. 升级前退出旧 App。保留一份常用安装副本，避免从多个旧版本交替启动。
3. 在设置中填写自己的 **TypeSafe API Key**，创建话题后点击 `Start Recording`。归类请求使用该 Key 的额度。
4. 录屏授权按 macOS 提示处理；需要时在系统设置中选择当前安装的 Dashcam，然后退出重开。

**适用设备：** Apple Silicon（M 系列芯片），macOS 14.0+。原生 Liquid Glass 图标外观需要 macOS 26；未在所有支持的系统版本上实机验证，本次不提供 Intel 版。

## 签名与首次打开

本版使用稳定的 **Apple Development** 证书签名，替代旧版 ad-hoc 签名；**尚未完成 Developer ID 签名与 Apple 公证**，因此继续作为体验版发布。升级自旧临时签名版本时，屏幕录制可能需要重新授权；后续更新继续使用相同应用标识和证书。

若 macOS 因无法验证开发者而阻止首次打开，请核对下载来源后，参照 [Apple 官方说明](https://support.apple.com/zh-cn/102445)处理「仍要打开」。无需关闭系统安全保护；若系统提示恶意软件或文件损坏，请停止使用并反馈。

## 资料与升级注意事项

- 安装包不包含个人数据库、截图、API Key 或开发环境配置。
- 自动迁移与更改存储位置都会保留原目录备份；新旧目录此后各自独立，后续数据只写入新位置。迁移完成后录制保持暂停，需手动开启。
- 不覆盖已有内容的目标目录；外置磁盘暂时断开时不会自动创建空资料库。
- 截图与 OCR 在本机处理，归类文字发送至 TypeSafe；分类请求不上传截图图片。API Key 仍保存在本机权限为 `0600` 的配置文件中，尚未接入 Keychain。
- OCR、模型分类与前台窗口排除的既有限制，见[使用指南](https://github.com/Gackson/Jev-dashcam/blob/v0.3.0/docs/usage.md)。

## 发布验证

27 项 Node 回归测试通过；Swift 话题快照、性能、窗口排除及原生存储迁移测试通过。发布包在独立源码目录构建，ZIP 解压后验证签名、版本、架构、原生图标图层及内置服务启动/退出。本机已验证资料迁移与新图标在系统「关于」窗口中的显示；未在其他 macOS 版本上进行安装验证。

下载后可用附带的 `SHA256SUMS.txt` 校验：

```bash
shasum -a 256 -c SHA256SUMS.txt
```
